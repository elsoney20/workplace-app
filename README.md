# workplace_app

Internal company social workplace app (feed, groups, chat).
Flutter + Riverpod + go_router + Supabase. Arabic/English with full RTL.

## Folder structure (feature-first)

```
lib/
  main.dart                 # Startup: env check, Supabase init, ProviderScope
  app.dart                  # MaterialApp.router: theme, locale, l10n delegates
  core/                     # Shared code used by every feature
    config/
      brand_config.dart     # <- App name, colors, logo. Change the brand HERE.
      app_env.dart          # Supabase URL + publishable key (from env.json)
    theme/app_theme.dart    # Light/dark themes generated from BrandConfig
    l10n/
      arb/app_en.arb        # English strings
      arb/app_ar.arb        # Arabic strings
      locale_controller.dart# Selected language (persisted)
      generated/            # Auto-generated by Flutter (git-ignored)
    router/app_router.dart  # go_router routes
    supabase/               # Supabase client + health check
    widgets/                # Shared widgets (BrandLogo, ...)
  features/
    home/presentation/      # Temporary Phase 0 screen
    # Later: auth/, feed/, groups/, chat/, notifications/, directory/, admin/
    # each with data/ (repositories), domain/ (models), presentation/ (UI)
supabase/
  config.toml               # Created by `supabase init`
  migrations/               # Versioned SQL schema (Phase 1+)
env.example.json            # Template for env.json (real keys, git-ignored)
```

## Run (Windows)

Prerequisites (once): Flutter stable, Visual Studio 2022 with the
"Desktop development with C++" workload, Windows Developer Mode
(`start ms-settings:developers`), and the Supabase CLI.

```powershell
copy env.example.json env.json   # then edit env.json with your Supabase values
flutter pub get
flutter run -d windows --dart-define-from-file=env.json
```

In VS Code, press F5 and pick "workplace_app (Windows)" (see `.vscode/launch.json`).

## Supabase CLI

```powershell
supabase login
supabase link --project-ref YOUR-PROJECT-REF
```

Schema changes are SQL files in `supabase/migrations/`, applied with
`supabase db push`.

Tests:

```powershell
flutter test
flutter analyze
```

## Secrets

- `env.json` holds the Supabase URL and the **publishable** (anon) key only.
  It is git-ignored.
- Never put the `service_role` / secret key in the app or in this repo.
